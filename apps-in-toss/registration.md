### 상세 설명

토스 홈 광고 선정에 활용되므로 접속 → 행동 → 결과 흐름으로 구체적으로 작성한다.

```text
폼 파티는 더러워진 카툰 차량을 도구를 바꿔 쓰며 빠르게 닦아내는 캐주얼 세차 게임이에요.

- 게임을 시작하면 흙탕물, 먼지, 낙엽, 벌레 자국, 오일 얼룩이 붙은 차량이 세차장으로 들어와요.
- 화면 하단에서 바람, 고압수, 비누, 스펀지 중 오물에 맞는 도구를 골라요.
- 차 위를 손가락으로 드래그하면 가벼운 오물은 바람에 날아가고, 굳은 얼룩은 비누로 불린 뒤 스펀지로 닦여요.
- 오물을 빠르게 연속으로 제거하면 콤보가 쌓이고, 세차를 마치면 완료 시간과 최고 콤보에 따라 별점과 코인을 받아요.
- 모은 코인으로 거품 폭탄을 터뜨리면 남은 오물 전체에 한 번에 비누칠이 돼요.
- 시티카, 스포츠카, 트럭이 번갈아 등장하고 레벨이 오를수록 오물 수와 체력이 조금씩 늘어나요.
- 첫 실행 가이드와 로컬 진행 저장을 제공해 별도 계정 없이 바로 플레이할 수 있어요.
```

## 4. 게임 등급분류 (출시 gate, 필수)

게임 앱은 등급 심의 증빙을 반드시 제출해야 한다. 폼 파티는 아직 오픈마켓 미출시라 현재 시점에는 제출 불가하며, 둘 중 하나로 진행한다.

- **경로 A (권장): 오픈마켓 자체등급분류 활용** — App Store 또는 Google Play 출시 완료 후 스토어 URL + 자체등급분류 게임물 정보(등록자명, 자체등급분류사업자명, 등급분류일자/번호, 이용등급, 내용정보)를 입력한다. [게임물관리위원회 자체등급분류 게임물 조회](https://www.grac.or.kr/Statistics/SelfRateGameStatistics.aspx)에서 오픈마켓에 출시한 게임을 먼저 조회 후 동일하게 기입한다.
- **경로 B: 게임물관리위원회 직접 심의** — 등급분류증명서 PDF를 첨부한다.

추가 제출물 (경로 A 기준):

- 대표자 인감 또는 사인 이미지 (흰 종이에 날인/서명 스캔)
- 오픈마켓 출시 게임 플레이 화면 2장 + 앱인토스 출시 게임 플레이 화면 2장 (무편집 원본)

## 5. 사업자 / 수익화 전제

- 사업자 등록 없이도 앱 등록·출시는 가능하지만 **인앱 광고, 인앱 결제, 토스 로그인은 사업자 등록 + 대표관리자 인증 필수**.
- 후속 수익화 후보(보상형 광고 부스터)를 진행하려면 워크스페이스 → 파트너 정보에서 사업자 정보 등록을 먼저 완료한다. 사업자 등록증 업종과 서비스 업종(게임)이 일치해야 한다.

# 썸네일 원판 (1932x1688 와이드 렌더 후 828 높이 크롭 + 워드마크 합성)
