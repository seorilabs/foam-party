# 폼 파티 게임 스펙

## 콘셉트

폼 파티는 모바일 우선 카툰풍 세차 게임입니다. 플레이어는 더러워진 차를 보고 이물질 종류에 맞는 청소 도구를 선택해 점점 깨끗하게 만듭니다.

## 핵심 루프

1. 여러 이물질이 붙은 차가 화면 밖에서 짧게 슬라이드 인합니다. 다음 차로 넘어갈 때는 기존 차량이 먼저 슬라이드 아웃합니다.
2. 플레이어가 청소 도구를 선택합니다.
3. 차 위를 드래그하면 선택한 도구가 적용됩니다.
4. 이물질은 `붙어 있음`, `젖음`, `비누 묻음`, `불림`, `흘러내림`, `날아감` 상태로 전이됩니다.
5. 상태에 맞는 도구를 쓰면 이물질이 날아가거나 흘러내리거나 닦여 사라집니다.
6. 오물을 2.5초 안에 연달아 제거하면 콤보가 쌓이고, 제거 효과음 피치가 콤보를 따라 올라갑니다.
7. 청결도가 충분히 오르면 완료 패널에서 별점(1~3개), 기록(시간, 최고 콤보), 무결점 보너스와 세차 전·후 리빌 카드를 보여주고 다음 차로 넘어갑니다.

## 콤보와 별점

- 콤보: 오물 하나를 완전히 제거할 때마다 +1, 마지막 제거 후 2.5초가 지나면 콤보당 한 번만 1초 보호 유예가 발동하고 두 번째 만료에서 0으로 리셋됩니다. 유예 안에 제거하면 콤보를 유지하며 보호는 재충전되지 않습니다. 다음 콤보가 새로 시작될 때 보호가 다시 충전됩니다. 콤보 2 이상이면 기존 콤보 배지가 떠오르고, 보호가 남아 있을 때 배지 안의 작은 민트 점이 켜지며 현재 레벨의 3별 요구 콤보에 도달하면 금색으로 바뀝니다.
- 별점 기준: 완료 시 1개 기본, 140초 이내 완료면 2개, 75초 이내 + 레벨별 최고 콤보 요구치 달성이면 3개. 콤보 요구치는 레벨 1~3의 4에서 시작해 3레벨마다 1씩 상승하고 최대 10으로 제한됩니다. 그레이드 트래커 안내와 게이트 통과 사운드·햅틱도 같은 요구치를 사용합니다.
- 손님 인내도는 140초 기준 경과 시간 압력에 세차 진행도를 함께 반영합니다. 진행도 0%에서는 기존 시간 곡선을 그대로 따르고, 진행도가 높을수록 시간 압력의 최대 65%를 완화하지만 세차를 멈추면 결국 0까지 감소합니다. 얼굴·기분·게이지 색과 경고음 존은 같은 계산값을 사용하며, 경고음은 실제 하락 전환마다 한 번만 재생합니다. 완료 순간 잔여 인내에는 `floor(인내도 × 12)`의 만족 팁을 지급하며 최대 12코인, 인내 0에서는 0코인입니다. 팁은 완료 보상에 합산하고 완료 패널의 고정 칩으로 별도 표시합니다.
- 모바일에서는 오물 제거 순간 짧은 햅틱이 울립니다.
- 별점과 잔여 인내는 서로 독립된 완료 보상 입력값입니다.

## 도구

- 바람: 낙엽과 먼지처럼 가벼운 오물을 차 밖으로 날려 보냅니다.
- 고압수: 흙탕물, 먼지, 비누칠된 오염을 아래로 흘려보내며 제거합니다.
- 비누: 오일, 벌레 자국, 굳은 흙, 나무 수액을 바로 제거하지 않고 `비누 묻음/불림` 상태로 바꿉니다.
- 스펀지: 비누나 물로 약해진 오일, 벌레 자국, 흙탕물, 도로 때를 문질러 제거합니다. 마른 도로 때는 먼저 고압수로 적셔 도장면의 모래를 걷어내고, 나무 수액은 반드시 비누로 연화한 뒤 닦습니다.

## 오물 매트릭스

타이틀의 도움말과 플레이 중 일시정지의 `세차 가이드`에서 같은 모달을 다시 열 수 있습니다. `오물 도감` 탭은 현재 8종 전체의 아이콘, 1차 도구, 후속 도구, 한 줄 제거법을 `Coaching` 규칙 순서로 표시하며 닫으면 이전 화면으로 즉시 돌아갑니다.

| 오물 | 1차 도구 | 후속 도구 | 연출 |
|---|---|---|---|
| 흙탕물 | 고압수, 비누 | 스펀지 | 젖고 묽어지며 흘러내림 |
| 먼지 | 고압수, 바람 | 없음 | 아래로 씻기거나 흩날림 |
| 낙엽 | 바람 | 없음 | 차 밖으로 날아감 |
| 오일 | 비누 | 스펀지, 고압수 | 비누로 불린 뒤 닦임/헹굼 |
| 벌레 자국 | 비누 | 스펀지, 고압수 | 불린 뒤 문질러 떨어짐 |
| 새똥 | 비누 | 고압수, 스펀지 | 불린 뒤 헹구거나 닦임 |
| 도로 때 | 고압수, 비누 | 스펀지 | 얇은 회갈색 막이 젖은 뒤 닦여 사라짐 |
| 나무 수액 | 비누 | 스펀지 | 물을 튕기는 호박색 수지 방울이 불린 뒤 닦임 |

## 비주얼

- 플레이 배경은 좌우 구조 기둥, 상부 레일과 세척 노즐, 양쪽 롤러, 바닥 배수 홈과 진입 가이드로 구성한 절차적 카툰 세차 베이입니다. 모든 환경 요소는 차량·오물·도구·HUD보다 먼저 그려 중앙 작업 영역의 판독성을 유지합니다.
- 차량은 정면을 바라보는 카툰 캐릭터 스타일입니다. 둥근 실루엣(Chaikin 스무딩), 큰 앞유리와 반사광, 눈처럼 보이는 헤드라이트, 웃는 그릴, 사이드미러로 구성합니다.
- 두 휠에는 기존 `mud` 규칙을 쓰는 전용 흙탕물 패치가 하나씩 배치됩니다. 오염은 밝은 휠 허브 위에 렌더되고, 고압수 또는 물로 적신 뒤 스펀지로 제거하면 기존 밝은 허브가 다시 드러납니다.
- 도로 때는 반복 무늬나 사각 외곽선 없이, 차체에 밀착된 불규칙한 반투명 회갈색 얼룩과 작은 흙 알갱이로 표현합니다.
- 나무 수액은 서로 이어진 반투명 호박색 방울, 가는 수지 실, 초승달 하이라이트로 표현해 오일과 구분합니다. 5레벨에 해금되어 이후 시티카 오염 풀에 등장하며 물만으로는 진행되지 않습니다.
- 오일은 어두운 얼룩 위에 고정 개수의 HSV 무지개 유막과 밝은 초승달형 광택 밴드를 겹쳐 벌레 자국과 구분합니다. 유막의 알파와 채도는 잔여 체력에 비례해 세차 중 함께 옅어집니다.
- 오물에 남는 비누 거품은 낮은 채도의 무지개 색조와 서로 다른 알파를 가진 큰 폼 덩어리·작은 위성 거품으로 구성합니다. 모든 거품은 좌상단 하이라이트와 옅은 외곽선을 가지며 비누량이 늘수록 개수와 덮임이 함께 증가합니다.
- 차종은 레벨에 따라 시티카 → 스포츠카 → 트럭 → 밴 → 오프로더 순으로 순환합니다. 시티카는 둥근 헤드라이트+안테나, 스포츠카는 눈꺼풀 있는 헤드라이트+후드 스쿱+사이드 벤트, 트럭은 각진 캐빈+루프랙+사각 헤드라이트+사다리 그릴, 밴은 높은 캐빈+분할 전면 유리+루프 마커, 오프로더는 루프랙+보조등+스키드 플레이트로 구분됩니다.
- 차량 꾸미기 시트의 다섯 번째 `차량` 탭에서 자동 순환 또는 코랄·민트·바이올렛 페인트를 선택합니다. 자동 순환은 기존 레벨별 차체 색상을 유지하고, 고정 페인트는 차종과 화면 상태가 바뀌어도 타이틀·게임·완료 차량에 같은 색을 적용합니다.
- 손님은 차종과 레벨 로테이션에 따라 얼굴색·머리색·모자·안경·헤어밴드 조합이 결정적으로 바뀝니다. 게임 중에는 기존 인내 표정과 콤보 응원 말풍선을 유지하고, 완료 패널 안에서는 획득 별 수에 따라 미소·점프·반짝임이 더 강해지는 만족 리액션을 재생합니다.
- 도구는 커서 원이 아니라 실제 도구로 보여줍니다: 물줄기를 쏘는 고압수 건, 바람 콘이 달린 송풍기, 거품을 분사하는 비누통, 거품이 묻은 2톤 스펀지.
- 세차 이펙트: 타격점의 부채꼴 스프레이+튀는 물방울+물안개(고압수), 모션 스트릭+소용돌이(바람), 하이라이트 있는 비눗방울(비누), 거품 자국(스펀지). 고압수가 차체 위를 지나면 실루엣 안에만 작은 비딩이 남고, 수명 후반에는 최대 20px의 가는 물길을 만들며 4초 안에 사라집니다. 표면 비딩은 40개 상한에서 오래된 방울부터 교체하고 다른 도구는 생성하지 않습니다. 고압수로 오물이 제거되면 콤보에 비례해 스플래시와 물안개가 강해지며, 연속 분사 효과는 72개 상한에서 오래된 물 효과부터 교체합니다. 다른 도구로 오물이 제거되면 반짝임 별과 거품 버스트가 터집니다. 전체 일시적 파티클은 192개 상한에서 가장 오래된 효과부터 교체합니다. 일시정지 설정의 `모션 줄이기`를 켜면 제거·진행 마일스톤·완료 버스트를 정상의 40%로 줄이고 제거 충격파 링, 콤보 전체 화면 플래시와 가장자리 글로우, 완료 글림 스윕, 차량 전환 이동을 생략합니다. 진행 바·오물 제거·별 공개·콤보 팬페어 문구는 유지하며 설정은 로컬 저장에 남습니다.
- 비누칠은 현재 차량의 `car_shapes` 실루엣 안에서 차체 전체 거품 커버리지로 누적되고, 물 도구로 씻으면 아래로 흐르며 걷힙니다. 거품 폭탄은 즉시 전체 커버리지와 1회 전면 버스트를 만들며, 일시적 bubble/foam 효과는 64개 상한에서 오래된 효과부터 교체합니다. 레벨 완료·재시작 시 커버리지와 runoff를 정리합니다.
- 차체 반사광은 세차 진행도에 따라 무광에서 또렷한 후드 하이라이트로 연속 증가합니다. 이 광택은 차체 렌더 내부에 그려져 남은 오염 아래에 가려지고, 완료 시 기존 전면 gleam 스윕으로 이어집니다. 저사양·모션 감소 연동을 위한 강도 조절점은 `CLEAN_SHINE_INTENSITY_SCALE` 한 곳입니다.
- 청결도 90% 이상에서 3초 동안 실제 제거 진행이 없으면 남은 오염마다 부드러운 이중 펄스 링과 네 방향 브래킷을 차체 위에만 표시합니다. 제거가 다시 진행되면 즉시 숨기며, 팝업·헤더·상시 HUD 요소는 추가하지 않습니다.
- 타이틀의 스테이지 시트는 최고 해금 레벨까지 과거 레벨을 다시 시작할 수 있고, 카드마다 차량·베스트타임·최고 별을 표시합니다. 미래 레벨은 잠금 카드로 미리 보여줍니다. 재도전은 레벨별 고정 시드를 그대로 사용하며, 현재 플레이 레벨과 최고 해금 진행도를 분리해 과거 레벨을 선택해도 이어하기 진행도는 되돌아가지 않습니다.
- UI는 둥근 카드 스타일: 타이틀에는 현재 레벨의 기존 절차적 차량 렌더를 축소한 깨끗한 히어로 카와 물·바람·비누·스펀지 장착 스킨 4색 프리뷰를 데일리 미션 위에 표시합니다. 플레이 중에는 상단 HUD 카드(타이틀+차량 배지+둥근 게이지), 툴바 위 도구 힌트 말풍선, 선택 시 떠오르는 도구 버튼, 별 3개가 뜨는 완료 패널을 사용합니다. 완료 패널은 레벨 시작 시점의 오물 종류·위치·반경·체력을 런타임 스냅샷으로 보존해 같은 절차적 차량 렌더의 `세차 전`·`세차 후` 미니 카드를 함께 표시하며, 완료 0.12초 뒤부터 0.8초 동안 세차 후 카드를 왼쪽에서 오른쪽으로 리빌합니다. 기존 거품 폭탄 버튼은 상시 1개의 `부스터` 진입점으로 유지하고, 탭하면 거품 폭탄·고압수 부스트 2개 카드만 담은 모달을 표시합니다. 누적 업적은 타이틀의 전용 버튼에서만 시트를 열어 확인하며 플레이 HUD에는 상시 요소를 추가하지 않습니다. 오적용 없이 마친 완료 패널에는 기존 마일스톤 칩 스타일의 `완벽!` 보너스 칩만 일시적으로 표시합니다. 구매 불가 부스터·업그레이드·스킨 카드는 색상과 함께 잠금 글리프를 표시하고, 손님 인내 게이지는 티어별 점·눈금·십자·경고 패턴을 사용해 색상 없이도 상태를 구분합니다. 일시정지·설정 시트에서는 한국어와 English를 즉시 전환하며, 명시 선택값은 저장하고 미선택 상태는 기기 언어를 따릅니다.
- 타이틀 우측 상단의 글자 배율 버튼은 `100% → 125% → 150%`를 순환하며 `settings/text_scale`에 즉시 저장합니다. 타이틀 주요 문구, 세차 가이드, 플레이 진행률·도구 힌트, 완료 패널 문구는 같은 배율 헬퍼를 사용하고 기존 카드 폭을 넘는 경우 원래 크기보다 작아지지 않는 범위에서 맞춥니다. 저장 키가 없는 기존 사용자는 100%로 시작하며 100%에서는 기존 폰트 크기와 배치를 그대로 유지합니다.

- 스펀지는 유리 마찰음 대신 말랑한 squish 리듬과 귀여운 boing을 씁니다.

## 경제와 메타

- 코인 보상: 세차 완료 시 `16 + 별점×8 + min(최고 콤보, 15)×2`와 잔여 인내 기반 만족 팁을 지급합니다. 만족 팁은 `floor(clamp(인내도, 0, 1) × 12)`로 최대 12코인이며 인내 0에서는 지급하지 않습니다. 같은 레벨을 다시 세차하면 기본·콤보·만족 팁·무결점 보상은 50%만 지급하되, 이전 최고 별보다 새로 늘어난 별의 `별당 8코인`은 전액 지급합니다. 완료 패널 코인 칩에는 `재세차 50%`를 함께 표시합니다. 기본 보상만 보면 1별·콤보 0은 24코인, 3별·콤보 10은 60코인, 3별·콤보 15 이상은 최대 70코인입니다. 오물 연속 제거 보너스도 콤보 5·8·10·12·15·20에서 각각 같은 수의 코인을 즉시 지급해 10콤보 이후 숙련 플레이를 계속 보상합니다.
- 무결점 세차: 같은 오물에서 처음으로 기존 오적용 코칭 힌트가 활성화될 때만 실수 1회를 기록합니다. 실수 없이 완료하면 별 1/2/3개에 각각 10/15/20코인을 추가하며, 짧은 빗나감과 같은 오물의 반복 힌트는 중복 집계하지 않습니다.
- 골드 스팟: 레벨 시드로 25% 확률에 최대 1개가 정해지며, 이중 원형 윤곽과 네 개의 다이아몬드 반짝임으로 색상 외에도 구분합니다. 제거 즉시 해당 위치에 `+8` 코인 팝과 짧은 상승음을 내고, 보상은 레벨당 1회로 제한합니다.
- 부스터: 기존 진입점을 누르면 모달에서 80코인 거품 폭탄 또는 60코인 고압수 부스트를 선택합니다. 거품 폭탄 가격은 1별·콤보 0 기본 완료 약 3.3회분을 목표로 하며, 콤보·무결점 플레이는 획득 간격을 의도적으로 단축합니다. 거품 폭탄은 남은 모든 오물에 비누칠·25% 즉시 세척을 적용하고, 고압수 부스트는 10초 동안 고압수 반경과 세기를 각각 1.5배로 높입니다. 부스터 모달이 열린 동안 레벨 타이머와 부스트 남은 시간은 정지하며, 같은 고압수 부스트의 중복 구매는 막습니다. 거품 폭탄은 준비된 보상형 광고가 있으면 코인 대신 광고 시청으로도 발동할 수 있습니다.
- 도구 업그레이드: `세기` 탭의 바람·고압수·비누·스펀지 네 트랙은 레벨별 `1.0x → 1.3x → 1.6x → 2.0x` 효과를 공유합니다. 비용은 바람 `80/160/280`, 고압수 `110/230/380`, 비누 `90/190/320`, 스펀지 `70/150/260` 코인이며 전체 구매 합계는 2,320코인입니다. 바람 세기는 낙엽·먼지의 직접 피해와 날아가는 동안의 제거 속도에 함께 적용됩니다. 같은 시트의 `반경` 탭은 네 도구 모두에 `1.0x → 1.12x → 1.24x → 1.36x`의 3단계 적용 범위 업그레이드를 제공합니다. 비용은 바람 `70/160/280`, 고압수 `80/180/300`, 비누 `75/170/290`, 스펀지 `60/140/240` 코인이며 세기 레벨과 독립 저장됩니다. 기존 저장에 바람 세기 키가 없으면 0단계로 복원하고 나머지 세기·반경 값은 유지합니다.
- 누적 업적: 로컬 플레이에서만 세차 완료 10대, 오물 제거 100개, 낙엽 제거 50개, 별 30개, 최고 콤보 x10을 추적합니다. 각 목표는 달성 즉시 80~120코인을 한 번만 지급하고 완료 상태를 잠급니다. 판정 규칙은 `product-core`에 두며 GA4나 외부 지표는 사용하지 않습니다.
- 진행 저장: `user://foam_party_save.cfg`에 차량 번호, 코인, 레벨별 최고 별, 5레벨 단위 마일스톤 보상 수령 이력, 세기·반경 업그레이드 레벨, 업적 카운터·지급 완료 상태, 노즐 스킨, 구매·선택한 차량 페인트, 번호판 문구, 설정(음악, 효과음, 모션 줄이기, 글자 배율, 언어, 가이드 노출 여부)을 저장합니다. 모은 별은 레벨별 최고 별의 합계로 매번 다시 계산해 재세차로 늘어나지 않으며, 레벨 5·10 등 마일스톤 보상은 각 레벨에서 최초 한 번만 지급합니다. 레벨별 기록이 없는 기존 저장은 최고 해금 레벨 안에서 종전 총 별을 레벨당 최대 3개로 보존적으로 분배하고, 이미 통과한 마일스톤은 수령 완료로 마이그레이션합니다. 완료 카드용 초기 오물 스냅샷은 현재 레벨의 런타임 메모리에만 두고 저장 포맷에는 포함하지 않습니다. 기존 저장에 반경 키가 없으면 모든 도구를 0단계로 복원하고 기존 세기 값을 유지합니다. 업적 완료와 코인 지급은 같은 저장 트랜잭션으로 처리하고 저장 실패 시 둘 다 롤백합니다. 기존 저장의 별 수는 신규 별 업적 진행도로 보존합니다. 노즐 스킨 소유권은 `도구:스킨` 키로 저장해 같은 `gold` 스킨도 물·에어·비누·스펀지별로 독립 구매합니다. 기존 flat 저장은 도구가 유일한 스킨만 해당 도구로 옮기고, 여러 도구가 공유하는 유료 스킨은 그 스킨을 선택했던 도구에만 복원하며, 무료 `classic`은 모든 도구에 유지합니다. 차량 페인트 미선택값은 기존 레벨별 자동 색상을 뜻하고, 미지원 저장값은 자동 순환으로 복구합니다. 번호판은 차량 꾸미기 시트의 검증된 대문자 프리셋만 선택할 수 있으며 미지원 저장값은 `FOAM`으로 복구합니다. 완료/설정 변경/앱 종료 시점에 저장하며, headless smoke와 스크린샷 캡처에서는 저장을 끕니다(`FOAM_DISABLE_SAVE=1`).
- 차량 로스터: 시티 → 스포츠 → 트럭 → 밴 → 오프로더 5종을 레벨 순서대로 순환합니다. 저장된 차량 번호는 `GameConfig.car_type_for_level()`로 같은 차종에 복원됩니다.
- 난이도 곡선: 총 오물 수는 `18 + 레벨 × 2`로 레벨 1의 20개에서 레벨 10의 38개까지 계속 늘고, 모바일 밀도 상한은 40개입니다. 이 중 2개는 좌우 휠 전용 흙탕물이고 나머지는 차체 후보 위치에 배치됩니다. 차체 후보는 현재 실루엣 안에서 중심 간격 25 이상을 보장하며, 24개 이후 패치 반경을 점진 축소해 40개에서 72%가 됩니다. 오물 체력 배율은 레벨 1의 1.0배에서 레벨당 +6%씩 증가해 레벨 9에서 1.48배가 되고, 레벨 10부터 1.5배 상한에 고정됩니다. 이후 난이도와 신선함은 체력 인플레가 아니라 오물 구성·배치·목표 변화로 확장합니다.
- 화면 흐름: 타이틀(이어하기 표시) → 첫 실행 시 세차 가이드 → 플레이 → 완료 패널(별점·코인·세차 전후) → 다음 차. 세차 가이드는 도구 설명과 8종 오물 도감 탭을 가지며 타이틀 도움말 또는 플레이 중 일시정지에서 언제든 다시 열 수 있습니다. 타이틀은 음악·효과음 상태를 각각 아이콘으로 표시하고, 플레이 중 우상단 일시정지 버튼에서는 계속하기, 현재 차 재시작, 음악·효과음 독립 설정, 언어, 모션 줄이기, 가이드, 홈, 종료 액션을 사용할 수 있습니다. 앱이 백그라운드로 전환되면 활성 세차를 멈추고 복귀 시 같은 일시정지 시트에서 재개하며, 이미 열린 튜토리얼·부스터·종료 확인은 중첩하지 않고 그대로 유지합니다.

## 게임 요소 도입 후보 (우선순위안)

1. ~~콤보/타이밍 보너스~~ → 1차 구현됨(`콤보와 별점` 참고). 남은 것: 콤보를 보상(코인)과 연결.
2. ~~손님 만족도~~ → 별점(시간+콤보 기반)으로 1차 구현됨. 남은 것: 손님 캐릭터/인내 게이지 연출.
3. ~~코인~~ → 1차 구현됨(`경제와 메타` 참고: 보상 공식, 거품 폭탄, 저장). 남은 것: 도구 반경/세기 업그레이드와 노즐 스킨 상점.
4. ~~차량 다양화~~ → 5종 로테이션 구현됨(시티카/스포츠카/트럭/밴/오프로더, 차종별 절차적 형상과 오염 프로필). 시티카는 도심 주차 테마로 먼지·낙엽·새똥·도로 때가 편중되고 흙탕물·오일·벌레는 낮은 빈도로 유지됩니다.
5. 데일리 미션: 날짜 해시로 오물 제거, 한 판 콤보 x8, 75초 이내 완료, 별 3개 세차 2회 중 하나를 결정론적으로 고릅니다. 플레이 스타일 미션은 기준값과 진행 목표를 분리해 기존 타이틀 카드와 상단 칩에서 `0/1` 또는 `0/2`로 진행되며, 보상은 50~100코인 범위에서 난이도별로 차등 지급합니다. 클리어 지급·저장·분석 이벤트는 기존 단일 보상 경로를 재사용합니다.

## 광고 전략

- 보상형(rewarded)은 현재 거품 폭탄의 대체 획득 경로로 제공합니다. 고압수 부스트는 우선 코인 싱크로 운영하며 광고 확장은 실제 사용률과 경제 지표를 확인한 뒤 결정합니다.
- 전면(interstitial)은 차량 N대(예: 3대) 완료 후 결과 화면 전환 시점에만 노출합니다. 첫 차량 완료 직후와 세차 도중에는 노출하지 않습니다.
- 배너는 드래그 조작 영역과 겹쳐 오조작을 유발하므로 기본적으로 쓰지 않습니다. 쓴다면 완료 패널이 떠 있는 동안으로 한정합니다.
- 광고 SDK는 gameplay script에 직접 섞지 않고 `AdPort`/`AdService` 뒤에 둡니다. AIT는 Toss Ads, Android/iOS는 AdMob을 사용하며 네이티브 singleton이 없는 빌드는 no-op입니다.
- 전면 노출 빈도는 현재 `INTERSTITIAL_EVERY=3` 로컬 규칙이고, Remote Config 전환은 후속 범위입니다.
