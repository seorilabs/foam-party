# 폼 파티 게임 스펙

## 콘셉트

폼 파티는 모바일 우선 카툰풍 세차 게임입니다. 플레이어는 더러워진 차를 보고 이물질 종류에 맞는 청소 도구를 선택해 점점 깨끗하게 만듭니다.

## 핵심 루프

1. 여러 이물질이 붙은 차가 화면 밖에서 짧게 슬라이드 인합니다. 다음 차로 넘어갈 때는 기존 차량이 먼저 슬라이드 아웃합니다.
2. 플레이어가 청소 도구를 선택합니다.
3. 차 위를 드래그하면 선택한 도구가 적용됩니다.
4. 이물질은 `붙어 있음`, `젖음`, `비누 묻음`, `불림`, `흘러내림`, `날아감` 상태로 전이됩니다.
5. 상태에 맞는 도구를 쓰면 이물질이 날아가거나 흘러내리거나 닦여 사라집니다.
6. 오물을 2.5초 안에 연달아 제거하면 콤보가 쌓이고, 제거 효과음 피치가 콤보를 따라 올라갑니다.
7. 청결도가 충분히 오르면 완료 패널에서 별점(1~3개)과 기록(시간, 최고 콤보)을 보여주고 다음 차로 넘어갑니다.

## 콤보와 별점

- 콤보: 오물 하나를 완전히 제거할 때마다 +1, 마지막 제거 후 2.5초가 지나면 콤보당 한 번만 1초 보호 유예가 발동하고 두 번째 만료에서 0으로 리셋됩니다. 유예 안에 제거하면 콤보를 유지하며 보호는 재충전되지 않습니다. 다음 콤보가 새로 시작될 때 보호가 다시 충전됩니다. 콤보 2 이상이면 기존 콤보 배지가 떠오르고, 보호가 남아 있을 때 배지 안의 작은 민트 점이 켜지며 현재 레벨의 3별 요구 콤보에 도달하면 금색으로 바뀝니다.
- 별점 기준: 완료 시 1개 기본, 140초 이내 완료면 2개, 75초 이내 + 레벨별 최고 콤보 요구치 달성이면 3개. 콤보 요구치는 레벨 1~3의 4에서 시작해 3레벨마다 1씩 상승하고 최대 10으로 제한됩니다. 그레이드 트래커 안내와 게이트 통과 사운드·햅틱도 같은 요구치를 사용합니다.
- 손님 인내도는 140초 기준 경과 시간 압력에 세차 진행도를 함께 반영합니다. 진행도 0%에서는 기존 시간 곡선을 그대로 따르고, 진행도가 높을수록 시간 압력의 최대 65%를 완화하지만 세차를 멈추면 결국 0까지 감소합니다. 얼굴·기분·게이지 색과 경고음 존은 같은 계산값을 사용하며, 경고음은 실제 하락 전환마다 한 번만 재생합니다.
- 모바일에서는 오물 제거 순간 짧은 햅틱이 울립니다.
- 별점은 추후 손님 만족도/보상(코인) 시스템의 입력값이 되는 것을 전제로 합니다.

## 도구

- 바람: 낙엽과 먼지처럼 가벼운 오물을 차 밖으로 날려 보냅니다.
- 고압수: 흙탕물, 먼지, 비누칠된 오염을 아래로 흘려보내며 제거합니다.
- 비누: 오일, 벌레 자국, 굳은 흙을 바로 제거하지 않고 `비누 묻음/불림` 상태로 바꿉니다.
- 스펀지: 비누나 물로 약해진 오일, 벌레 자국, 흙탕물, 도로 때를 문질러 제거합니다. 마른 도로 때는 먼저 고압수로 적셔 도장면의 모래를 걷어냅니다.

## 오물 매트릭스

| 오물 | 1차 도구 | 후속 도구 | 연출 |
|---|---|---|---|
| 낙엽 | 바람 | 고압수 약함 | 차 밖으로 날아감 |
| 먼지 | 바람, 고압수 | 없음 | 흩날림 또는 아래로 씻김 |
| 흙탕물 | 고압수 | 스펀지 보조 | 젖고 묽어지며 흘러내림 |
| 오일 | 비누 | 고압수, 스펀지 | 비누로 불린 뒤 헹굼/닦임 |
| 벌레 자국 | 비누 | 스펀지, 고압수 | 불린 뒤 문질러 떨어짐 |
| 도로 때 | 고압수, 비누 | 스펀지 | 얇은 회갈색 막이 젖은 뒤 닦여 사라짐 |

## 비주얼

- 차량은 정면을 바라보는 카툰 캐릭터 스타일입니다. 둥근 실루엣(Chaikin 스무딩), 큰 앞유리와 반사광, 눈처럼 보이는 헤드라이트, 웃는 그릴, 사이드미러로 구성합니다.
- 두 휠에는 기존 `mud` 규칙을 쓰는 전용 흙탕물 패치가 하나씩 배치됩니다. 오염은 밝은 휠 허브 위에 렌더되고, 고압수 또는 물로 적신 뒤 스펀지로 제거하면 기존 밝은 허브가 다시 드러납니다.
- 도로 때는 반복 무늬나 사각 외곽선 없이, 차체에 밀착된 불규칙한 반투명 회갈색 얼룩과 작은 흙 알갱이로 표현합니다.
- 오일은 어두운 얼룩 위에 고정 개수의 HSV 무지개 유막과 밝은 초승달형 광택 밴드를 겹쳐 벌레 자국과 구분합니다. 유막의 알파와 채도는 잔여 체력에 비례해 세차 중 함께 옅어집니다.
- 차종은 레벨에 따라 시티카 → 스포츠카 → 트럭 → 밴 → 오프로더 순으로 순환합니다. 시티카는 둥근 헤드라이트+안테나, 스포츠카는 눈꺼풀 있는 헤드라이트+후드 스쿱+사이드 벤트, 트럭은 각진 캐빈+루프랙+사각 헤드라이트+사다리 그릴, 밴은 높은 캐빈+분할 전면 유리+루프 마커, 오프로더는 루프랙+보조등+스키드 플레이트로 구분됩니다.
- 차량 꾸미기 시트의 다섯 번째 `차량` 탭에서 자동 순환 또는 코랄·민트·바이올렛 페인트를 선택합니다. 자동 순환은 기존 레벨별 차체 색상을 유지하고, 고정 페인트는 차종과 화면 상태가 바뀌어도 타이틀·게임·완료 차량에 같은 색을 적용합니다.
- 손님은 차종과 레벨 로테이션에 따라 얼굴색·머리색·모자·안경·헤어밴드 조합이 결정적으로 바뀝니다. 게임 중에는 기존 인내 표정과 콤보 응원 말풍선을 유지하고, 완료 패널 안에서는 획득 별 수에 따라 미소·점프·반짝임이 더 강해지는 만족 리액션을 재생합니다.
- 도구는 커서 원이 아니라 실제 도구로 보여줍니다: 물줄기를 쏘는 고압수 건, 바람 콘이 달린 송풍기, 거품을 분사하는 비누통, 거품이 묻은 2톤 스펀지.
- 세차 이펙트: 타격점의 부채꼴 스프레이+튀는 물방울+물안개(고압수), 모션 스트릭+소용돌이(바람), 하이라이트 있는 비눗방울(비누), 거품 자국(스펀지). 고압수로 오물이 제거되면 콤보에 비례해 스플래시와 물안개가 강해지며, 연속 분사 효과는 72개 상한에서 오래된 물 효과부터 교체합니다. 다른 도구로 오물이 제거되면 반짝임 별과 거품 버스트가 터집니다. 전체 일시적 파티클은 192개 상한에서 가장 오래된 효과부터 교체합니다.
- 비누칠은 현재 차량의 `car_shapes` 실루엣 안에서 차체 전체 거품 커버리지로 누적되고, 물 도구로 씻으면 아래로 흐르며 걷힙니다. 거품 폭탄은 즉시 전체 커버리지와 1회 전면 버스트를 만들며, 일시적 bubble/foam 효과는 64개 상한에서 오래된 효과부터 교체합니다. 레벨 완료·재시작 시 커버리지와 runoff를 정리합니다.
- 차체 반사광은 세차 진행도에 따라 무광에서 또렷한 후드 하이라이트로 연속 증가합니다. 이 광택은 차체 렌더 내부에 그려져 남은 오염 아래에 가려지고, 완료 시 기존 전면 gleam 스윕으로 이어집니다. 저사양·모션 감소 연동을 위한 강도 조절점은 `CLEAN_SHINE_INTENSITY_SCALE` 한 곳입니다.
- 청결도 90% 이상에서 3초 동안 실제 제거 진행이 없으면 남은 오염마다 부드러운 이중 펄스 링과 네 방향 브래킷을 차체 위에만 표시합니다. 제거가 다시 진행되면 즉시 숨기며, 팝업·헤더·상시 HUD 요소는 추가하지 않습니다.
- 타이틀의 스테이지 시트는 최고 해금 레벨까지 과거 레벨을 다시 시작할 수 있고, 카드마다 차량·베스트타임·최고 별을 표시합니다. 미래 레벨은 잠금 카드로 미리 보여줍니다. 재도전은 레벨별 고정 시드를 그대로 사용하며, 현재 플레이 레벨과 최고 해금 진행도를 분리해 과거 레벨을 선택해도 이어하기 진행도는 되돌아가지 않습니다.
- UI는 둥근 카드 스타일: 상단 HUD 카드(타이틀+차량 배지+둥근 게이지), 툴바 위 도구 힌트 말풍선, 선택 시 떠오르는 도구 버튼, 별 3개가 뜨는 완료 패널. 일시정지·설정 시트에서는 한국어와 English를 즉시 전환하며, 명시 선택값은 저장하고 미선택 상태는 기기 언어를 따릅니다.

## 사운드

- 도구별 효과음은 코드에서 런타임 합성한 짧은 WAV 루프이며, 현실 묘사보다 카툰 게임 톤을 우선합니다.
- 바람은 부드러운 바람 스웰에 가벼운 휘파람 톤이 흔들리는 소리입니다.
- 고압수는 거친 타격음 대신 보글거리는 물 흐름과 음계를 따라 떨어지는 물방울 플링크를 씁니다.
- 비누는 펜타토닉 음계로 터지는 거품 팝과 몽글몽글한 fizz를 겹칩니다.
- 스펀지는 유리 마찰음 대신 말랑한 squish 리듬과 귀여운 boing을 씁니다.
- 오물이 제거될 때마다 거품 팝+차임 제거 효과음이 피치를 바꿔 재생됩니다.
- 배경음악도 외부 파일 없이 런타임 합성합니다.
- Headless smoke에서는 오디오 스트림 생성만 검증하고 playback은 끕니다.

## 경제와 메타

- 코인 보상: 세차 완료 시 `16 + 별점×8 + min(최고 콤보, 10)×2` 코인을 지급합니다. 초기 공식보다 최대 콤보 보상 기준 약 15% 낮춘 의도적 경제 조정값입니다.
- 골드 스팟: 레벨 시드로 25% 확률에 최대 1개가 정해지며, 이중 원형 윤곽과 네 개의 다이아몬드 반짝임으로 색상 외에도 구분합니다. 제거 즉시 해당 위치에 `+8` 코인 팝과 짧은 상승음을 내고, 보상은 레벨당 1회로 제한합니다.
- 거품 폭탄: 코인 40으로 남아 있는 모든 오물에 비누칠(불림)을 적용하는 부스터입니다. 보상형 광고가 들어오면 광고 시청이 대체 획득 경로가 될 자리입니다.
- 진행 저장: `user://foam_party_save.cfg`에 차량 번호, 코인, 모은 별, 노즐 스킨, 구매·선택한 차량 페인트, 번호판 문구, 설정(사운드, 가이드 노출 여부)을 저장합니다. 노즐 스킨 소유권은 `도구:스킨` 키로 저장해 같은 `gold` 스킨도 물·에어·비누·스펀지별로 독립 구매합니다. 기존 flat 저장은 도구가 유일한 스킨만 해당 도구로 옮기고, 여러 도구가 공유하는 유료 스킨은 그 스킨을 선택했던 도구에만 복원하며, 무료 `classic`은 모든 도구에 유지합니다. 차량 페인트 미선택값은 기존 레벨별 자동 색상을 뜻하고, 미지원 저장값은 자동 순환으로 복구합니다. 번호판은 차량 꾸미기 시트의 검증된 대문자 프리셋만 선택할 수 있으며 미지원 저장값은 `FOAM`으로 복구합니다. 완료/설정 변경/앱 종료 시점에 저장하며, headless smoke와 스크린샷 캡처에서는 저장을 끕니다(`FOAM_DISABLE_SAVE=1`).
- 차량 로스터: 시티 → 스포츠 → 트럭 → 밴 → 오프로더 5종을 레벨 순서대로 순환합니다. 저장된 차량 번호는 `GameConfig.car_type_for_level()`로 같은 차종에 복원됩니다.
- 난이도 곡선: 총 오물 수는 `18 + 레벨 × 2`로 레벨 1의 20개에서 레벨 10의 38개까지 계속 늘고, 모바일 밀도 상한은 40개입니다. 이 중 2개는 좌우 휠 전용 흙탕물이고 나머지는 차체 후보 위치에 배치됩니다. 차체 후보는 현재 실루엣 안에서 중심 간격 25 이상을 보장하며, 24개 이후 패치 반경을 점진 축소해 40개에서 72%가 됩니다. 오물 체력은 현재 레벨당 +6% 증가합니다.
- 화면 흐름: 타이틀(이어하기 표시) → 첫 실행 시 세차 가이드 → 플레이 → 완료 패널(별점·코인) → 다음 차. 플레이 중 우상단 일시정지 버튼에서 계속하기, 현재 차 재시작, 사운드, 가이드, 홈, 종료 액션을 사용할 수 있습니다.

## 게임 요소 도입 후보 (우선순위안)

1. ~~콤보/타이밍 보너스~~ → 1차 구현됨(`콤보와 별점` 참고). 남은 것: 콤보를 보상(코인)과 연결.
2. ~~손님 만족도~~ → 별점(시간+콤보 기반)으로 1차 구현됨. 남은 것: 손님 캐릭터/인내 게이지 연출.
3. ~~코인~~ → 1차 구현됨(`경제와 메타` 참고: 보상 공식, 거품 폭탄, 저장). 남은 것: 도구 반경/세기 업그레이드와 노즐 스킨 상점.
4. ~~차량 다양화~~ → 5종 로테이션 구현됨(시티카/스포츠카/트럭/밴/오프로더, 차종별 절차적 형상과 오염 프로필). 시티카는 도심 주차 테마로 먼지·낙엽·새똥·도로 때가 편중되고 흙탕물·오일·벌레는 낮은 빈도로 유지됩니다.
5. 데일리 미션: 날짜 해시로 오물 제거, 한 판 콤보 x8, 75초 이내 완료, 별 3개 세차 2회 중 하나를 결정론적으로 고릅니다. 플레이 스타일 미션은 기준값과 진행 목표를 분리해 기존 타이틀 카드와 상단 칩에서 `0/1` 또는 `0/2`로 진행되며, 보상은 50~100코인 범위에서 난이도별로 차등 지급합니다. 클리어 지급·저장·분석 이벤트는 기존 단일 보상 경로를 재사용합니다.

## 광고 전략

- 보상형(rewarded)을 기본 축으로 합니다: "거품 폭탄(전체 오물 비누칠)", "고압수 부스트" 같은 부스터를 광고 시청으로 제공해 플레이어가 광고를 선택하게 만듭니다.
- 전면(interstitial)은 차량 N대(예: 3대) 완료 후 결과 화면 전환 시점에만 노출합니다. 첫 차량 완료 직후와 세차 도중에는 노출하지 않습니다.
- 배너는 드래그 조작 영역과 겹쳐 오조작을 유발하므로 기본적으로 쓰지 않습니다. 쓴다면 완료 패널이 떠 있는 동안으로 한정합니다.
- 광고 SDK는 gameplay script에 직접 섞지 않고 `AdPort`/`AdService` 뒤에 둡니다. AIT는 Toss Ads, Android/iOS는 AdMob을 사용하며 네이티브 singleton이 없는 빌드는 no-op입니다.
- 전면 노출 빈도는 현재 `INTERSTITIAL_EVERY=3` 로컬 규칙이고, Remote Config 전환은 후속 범위입니다.
